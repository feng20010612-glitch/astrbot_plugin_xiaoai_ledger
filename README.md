# 小爱记账（AstrBot 插件）

> 记账项目本体（源码 / Releases 下载）：https://github.com/feng20010612-glitch/xiaoai-ledger

让 QQ 也能记账：聊天里随手记一笔，详细数据回到记账本网页里看。
插件只调用记账本**现成的 HTTP 接口**，不修改记账本、不写它的任何文件。

---

## 一、它由两部分组成

| 部分 | 是什么 | 在哪 |
| --- | --- | --- |
| **记账本程序** | 本地运行的桌面程序（小爱记账.exe），有网页界面、图表、账单、预算、回收站 | 你自己放在某个目录，例如 D:\小爱记账\小爱记账.exe |
| **本插件** | AstrBot 插件，负责在 QQ 里读写记账本的数据 | AstrBot 的 data/plugins/astrbot_plugin_xiaoai_ledger/ |

两者通过 HTTP 通信：记账本在本机提供 http://127.0.0.1:8899 ，插件就是它的"遥控器"。
**插件包本身只有 4 个文件，不含记账程序**；记账程序请从发布页 / 仓库 Releases 下载，
或向发布者索取（目录里应该有 小爱记账.exe、记账本-v2.html、chart.umd.min.js、icon.ico、data\ 等）。

---

## 二、五步用起来

1. **拿到记账程序**：解压到一个固定目录，例如 D:\小爱记账\
2. **打开记账程序**：双击 小爱记账.exe （或桌面快捷方式），浏览器会自动打开
   http://127.0.0.1:8899/ —— 这就是记账本的网页界面
3. **装插件**：把 astrbot_plugin_xiaoai_ledger 放进 AstrBot 的 data/plugins/，重启 AstrBot
4. **填配置**（AstrBot 面板 → 插件 → 小爱记账）：
   - base_url：默认 http://127.0.0.1:8899 ，端口没改就不用动
   - exe_path：填第 1 步那个 exe 的**完整路径**，插件才能在记账本没开时自动帮你拉起来
   - allow_ids：建议填你自己的 QQ 号，别人就不能动你的账
5. 在 QQ 里发 /账本状态 确认连上了（会显示地址、版本、记录条数）

---

## 三、记账程序在哪、怎么打开

- **在哪**：你解压的那个目录。桌面上的快捷方式右键 → 属性 → 目标，也能看到完整路径
- **怎么打开**：双击 小爱记账.exe；它会自己起服务并打开 http://127.0.0.1:8899/
- **不想每次手动开**：把 exe_path 填进插件配置，聊天里记账时若连不上会自动拉起
  （不会弹浏览器、不会弹黑框；等 start_timeout 秒后重试）
- **端口被占 / 想开第二个账本**：给另一个实例换端口，插件里把 base_url 改成对应端口

## 四、两套界面怎么分工

| 场景 | 用什么 |
| --- | --- |
| 随手记一笔、问这个月花了多少 | **QQ 里跟机器人说**（快，几秒） |
| 看图表、翻账单、改记录、设预算、回收站恢复、导出 | **打开记账本网页**（http://127.0.0.1:8899/ ，数据最全） |

QQ 里只做"记账 / 查账 / 月度统计 / 删除"，**详细数据和可视化都在记账本网页里看**。

## 首次安装：插件帮你把记账程序装好

插件本身很小（只有 4 个文件），**记账程序按需下载**，不用另外找地方下：

1. 在配置里填 `app_url` = 记账程序包的下载直链（zip）；或者把包放本地，填 `app_zip_path`
2. 在 QQ 里发 `/账本安装`
   - 插件下载 → 解压到自己的数据目录 `ledger_app/` → 自动找到 exe → 记住路径
   - 也可以直接发 `/账本安装 https://.../xxx.zip`
3. 打开它：按回执里的**完整路径**去双击那个 exe；或把 `auto_start` 打开，让插件自己拉起
4. 发 `/账本状态` 确认识别到账本

想装到别处就自己解压，再把 `exe_path` 填成那个 exe 的完整路径。

安全限制：只接受 https 下载地址（本机地址除外）、包 ≥1KB 且 ≤200MB、
逐条检查 zip 内部路径防止目录穿越、解压后体积上限 400MB。

## 六、自然语言（LLM 工具）

不用记指令，直接说话就行（需要 AstrBot 配好大模型）：

- 「记一笔午饭 25」「打车花了 23」「工资到账 5000」→ 自动记账
- 「我最近记了什么」「这个月吃饭花了多少」→ 自动查账
- 「这个月花了多少」「预算还剩多少」→ 自动统计

插件注册的工具：ledger_add / ledger_query / ledger_month / ledger_categories。
其中**没有删除**，模型不会误删；分类非法会被自动纠正到真实分类。

## 七、配置项

| 键 | 说明 |
| --- | --- |
| base_url | 记账本地址，默认 http://127.0.0.1:8899 |
| allow_ids | 允许使用的 QQ 号，逗号分隔；留空=不限制 |
| only_private | 只在私聊允许（默认 false）|
| default_category | 猜不到分类时的兜底一级分类 |
| auto_start | 连不上时自动启动记账本（默认 false，需配 exe_path）|
| exe_path | 记账程序完整路径，例如 D:\小爱记账\小爱记账.exe |
| start_timeout | 自动启动后等待就绪的秒数，默认 20 |
| update_url | 升级包下载直链（zip）|
| update_zip_path | 升级包本地路径 |
| allow_restart | 允许插件重启记账本（默认 false）|

## 八、多账本

插件认地址不认文件夹。一台电脑开两个账本时用不同端口：

- 正式：base_url = http://127.0.0.1:8899
- 测试：base_url = http://127.0.0.1:8907

发 /账本状态 看「记录总数」，空账本是 0 条，一眼能分辨。

---

## 九、升级记账本

1. 插件取包（命令里的地址 / 本地 zip / 配置里的 update_url 或 update_zip_path）
2. base64 提交 POST /api/upgrade —— 校验、备份旧程序、只换程序文件，data\ 一律不动
3. exe 正在跑时，记账本会把它存成 小爱记账.exe.new，并生成 _upgrade_restart.bat
4. 发 /账本重启 → GET /api/shutdown?relaunch=1 → 助手把 .new 换成正式 exe 并重新拉起

所以插件不必跟着升级：只要记账本的升级接口不变，它一直能用。

## 主动提醒说明

- 待还提醒：到期前 lead_days 天推一次（默认 3 天），不会每天刷屏；
  算法与网页总览的「待还账单」卡片一致（分期按剩余期数、受总期数上限约束）。
- 预算预警：每天记账后若本月预算用到 budget_warn_pct（默认 80%）当场提醒，超支会写明金额。
- 提醒发送到 notify_target，留空则用最近一次说话的会话。


## 十、隐私与安全

- 插件只发 HTTP 请求，**不读不写记账本目录**，不会覆盖 exe / 数据 / 设置
- 默认 exe_path 为空、auto_start 为关：不会自动启动任何程序
- 升级包 200MB 上限、只替换白名单程序文件、data\ 不参与
- 建议填写 allow_ids，避免他人通过机器人动你的账本

## 计算口径（与记账本网页完全一致）

插件不自己发明算法，下面每条都对应记账本前端同名函数，改完后用真实数据对拍验证过。

- **支出**：只算支出记录，**排除**「投资理财 / 理财存入 / 理财基金」和「储蓄存款 / 存入存款」这类非消费；
  已关联退款的支出按「金额 − 退款额」计，不足 0 记 0。
- **收入**：只算收入记录，**排除**「投资赎回 / 理财取出」和「储蓄取出 / 取出存款」；
  已关联原支出的退款不计入（支出那边已冲抵），未关联的退款正常计入。
- **结余** = 本月收入 − 本月支出（都按上面的口径）。
- **预算**：本月基础预算 + 上月结余（上月结余 = 上月生效预算 − 上月净支出），**逐月递推**；
  链起点是「重置月」或最早单独设置过预算的月份；上月没设预算或上月无账目则停止结转；
  设置里关掉「预算结转」时不做结转。
- **预算已用**：只算消费类支出；「投资亏损」默认不计入（记账本设置里可打开）。
- **待还提醒**：只统计分期（期数 ≥ 2）与循环账单；剩余期数从「今天所在月」与「开始月」较晚者算到结束月（含），
  并受总期数上限约束。

验证记录（2026-10 真实数据对拍，网页 vs 插件）：支出 1731.26 / 收入 11717.62 / 结余 9986.36 /
生效预算 2260.32 / 预算已用 1731.26 —— 五项完全一致。
